# Contributing to CodeAtlas

Thank you for contributing to CodeAtlas.

CodeAtlas is intended to become a serious engineering and research project focused on personalized programming education.

Contributions should therefore prioritize:

Correctness
+
Learning value
+
Evidence
+
Maintainability
+
Security

over simply adding features.

1. Before Contributing

Read the project documentation first.

Start with:

README.md \
docs/VISION.md\
docs/Problem_Statement.md\
docs/System_Architecture.md\
docs/PRD.md\
docs/DESIGN.md\
docs/ROADMAP.md\
AGENTS.md

The documentation defines the intended behavior of the system.
